# Спецификация формата данных: `catalog.csv`

**Описание:** Файл содержит каталог товаров для импорта в систему.

## Правила парсинга
* **Кодировка:** UTF-8
* **Разделитель (Delimiter):** Запятая `,`
* **Массив** Разделение `;`
* **Ограничитель строк (Line Terminator):** `\n` или `\r\n`
* **Первая строка:** Заголовки (обязательна)

`-` не используемы параметры.

**SKU** (Stock Keeping Unit) — это уникальный внутренний код конкретной товарной позиции

**Ext_product_id** (External Product ID) — внешний идентификатор товара, присвоенный поставщиком, производителем или другим сервисом (например, штрихкод EAN), по которому товар распознается за пределами вашей системы.
