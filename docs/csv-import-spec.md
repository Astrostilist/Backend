# Спецификация формата данных: `catalog.csv`

**Описание:** Файл содержит каталог товаров для импорта в систему.

## Правила парсинга
* **Кодировка:** UTF-8
* **Разделитель (Delimiter):** Запятая `,`
* **Ограничитель строк (Line Terminator):** `\n` или `\r\n`
* **Кавычки (Quote char):** Двойные кавычки `"` (используются для текстовых полей, содержащих запятые)
* **Первая строка:** Заголовки (обязательна)

## Структура колонок


| Название колонки | Тип данных | Обязательное | Описание / Ограничения | Пример значения |
| :--- | :--- | :--- | :--- | :--- |
| `ext_product_id` | String | Да | ID товара из внешней системы (CRM/магазин). Обязательный префикс `PROD-` | `PROD-123` |
| `title` | String | Да | Название товара | `"Куртка"` |
| `price` | Float64 | Да | Цена в валюте магазина. `price > 0`  | `15990.00` |
| `url` | String | Да | Прямая ссылка на страницу товара.  Валидный HTTP(S). | `"https://..."` |
| `images` | Array | Нет | Массив URL изображений товара. Разделен символом `;`. Валидный HTTP(S) | `"https://img1.jpg;https://img2.jpg"` |
| `tags` | Array | Нет | Массив строковых тегов для поиска. Разделен символом `;` | `"red;leather;sport"` |

## Пример содержимого (Payload)
```csv
ext_product_id,title,price,url,images,tags
PROD-123,"Куртка",15990.00,"https://...", "https://img1.jpg;https://img2.jpg", "red;leather;sport"
```
